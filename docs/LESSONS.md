# Lessons

Mistakes already paid for. Every agent reads this before working. Add one dated row when
you learn something a future run must not re-learn; prune rows that no longer apply.

| Date | Lesson | What happened |
|---|---|---|
| 2026-10-16 | A "canvas is not blank" check must hide everything layered over the canvas first | An element screenshot captures the HUD and panels drawn on top, so a dead WebGL canvas still showed many colours. `distinctColours()` now hides overlays; render on = 6 colours, render off = 1. |
| 2026-10-16 | Write expected values from an independent calculation, then verify it | A hand-guessed tile Y (3300) was wrong; the code (3302) was right. Recompute with a separate tool before "fixing" code to match a test. |
| 2026-10-16 | Stub the Esri tile host in tests | Tests must not depend on a third-party server or rate limits. `stubTiles()` serves a 1x1 PNG with CORS headers. |
| 2026-10-16 | **Coplanar ground layers: order them, don't offset them.** | Runways at y=0.35 lost to imagery at y=0.05 on a 4 NM final (24-bit depth, near 0.5 m, far 95 km). Nothing is ever below the ground, so ground layers draw first with `depthWrite: false` in `renderOrder`; no polygonOffset, no log depth. |
| 2026-10-16 | **Lights are Points, not spheres.** | 120 instanced PAPI spheres cost ~6 ms/frame in SwiftShader (CI). One `THREE.Points` with `sizeAttenuation: false` costs ~0 and reads from miles out like a real lamp. |
| 2026-10-16 | **Check the data before the test.** | A unit test asserted Love Field is north of KDFW; OurAirports says 32.84°N vs 32.90°N — south-east. The data was right. |
| 2026-10-16 | **Stub same-origin APIs in e2e too.** | `vite preview` has no Worker, so `/openaero/api/metar` 404s — and Chromium logs failed loads as console errors, which the zero-error smoke tests catch. `stubTiles()` now also serves a fixed METAR. |
| 2026-10-16 | **Edge cache headers can be rewritten.** | On cache HITs the zone's Browser Cache TTL stretched the METAR response to `max-age=14400`. Weather is fetched with `cache: 'no-store'` plus a minute-bucket query param; the Worker re-stamps cache-control on hits. |
| 2026-10-16 | **Test that the aircraft flies, not just that the page renders.** | The ported prototype passed every boot/render test while D banked left, banks never turned, takeoff capped at 75 kt and autoland looped into the ground (in production). `flight.spec.js` now rolls, turns, takes off and autolands. |
| 2026-10-16 | **Pin control-law signs with unit tests.** | The glideslope law `(target − pitch)·k` was positive feedback because elevator + is nose-down here. `src/autopilot.js` laws each have a sign test. |

| 2026-10-17 | Scout: playing needs the Esri host stubbed, not blocked | Blocking tiles with 404s floods the console with errors that look like bugs; fulfil with a 1x1 PNG + CORS like `stubTiles()`. |
| 2026-10-17 | **The ground is not y = 0.** | Since #0023 y is height above KDFW's 606 ft; use `sim.groundY` for AGL/contact and `end.thrY` for approach/PAPI. On sloped runways, sub-nanometre drift changed the ground by 1e-13 m and broke gear contact: compare with a tolerance. |
| 2026-10-17 | **three ≥ r151 lights Lambert per pixel.** | Full-screen Lambert ground doubled CI (SwiftShader) frame time after the r186 upgrade and made real-time e2e flaky. Ground is unlit + tinted (`applyGroundLight`), relief shading baked in vertex colours. |
| 2026-10-17 | **Auto-merged PRs don't trigger CI on main.** | Merges made with the workflow's GITHUB_TOKEN create no new workflow runs, so main's own CI didn't run after agent merges. A red main can go unnoticed: check the PR's CI, not main's. |
| 2026-10-17 | **Path-restricted Google keys need a full Referer.** | Browsers send only the origin on cross-origin requests, so a key restricted to `mutaafaziz.com/openaero/*` got `API_KEY_HTTP_REFERRER_BLOCKED` in production while every stubbed test passed. Google fetches use `referrerPolicy: 'no-referrer-when-downgrade'`; the e2e now asserts the Referer path. |
| 2026-10-17 | **"Executable doesn't exist" is not a red test.** | `npm ci` pulls a Playwright newer than the sandbox's preinstalled Chromium, so every e2e "fails" at launch. Never `playwright install`; run with a throwaway config that spreads `playwright.config.js` and sets `launchOptions.executablePath: '/opt/pw-browsers/chromium'` on every project (keep it out of git). |
| 2026-10-17 | Scout: phone landscape (844x390) was never tested | Portrait-only layout checks left the landscape HUD overlapping itself (coach on tapes, button column over the horizon); layout tests must cover both orientations. |
| 2026-10-17 | **Measure frame time alone.** | The perf probe shared the 2-core CI runner with a parallel SwiftShader flight test: the same build measured 207, 236, 314 and 255 ms and turned main red on a docs-only commit. It now runs in its own `perf` Playwright project after every other test (threshold unchanged). |
| 2026-10-18 | **A focused control is not a held control.** | 0017 first skipped the throttle-slider sync while `#rngThrottle` was `document.activeElement`; range inputs keep focus after a click, so the slider froze and an arrow key snapped the throttle back. Guard on an actual drag (pointerdown → pointerup). |
| 2026-10-18 | **The sim runs behind the modal.** | 0018's spawn-alignment e2e read the heading after tapping Start: by then the aircraft had weathervaned 7.5° into a 15 kt crosswind. Read spawn state right after the mission loads, not after a later UI step. |
| 2026-10-18 | **Self-review before you open the PR.** | Auto-merge squash-merged #30 seven minutes after it opened, while the adversarial review was still running; its fixes (paused marker hidden behind the phone menu, Escape/focus, more tests) had to ship as a second PR. Run the review on the local diff first, or open the PR as a draft until it's done. |
| 2026-10-18 | **A media query covers more than the ticket's sizes.** | 0025's landscape layout passed at the ticket's 844x390 and 667x375, but the same query matches 640x360 and 568x320, where the stick sat on the altitude tape and the moved TRK box met the alert banners. Test the narrowest screen a query matches, and force transient overlays (alerts) visible in layout tests. |
| 2026-10-18 | **Bigger text resizes auto-width panels.** | 0007 bumped 8 px labels to 10 px: the EICAS aside (`w-68`/`w-76` aren't Tailwind classes, so it sizes to content) widened under the coach at 1280x720, and "V/S FPM" wrapped in 568x320's 41 px column, pushing the top bar to 63 px. Run every layout spec after a font change; keep long footnotes out of the width (`w-0 min-w-full`), labels `whitespace-nowrap`. |
| 2026-10-18 | Scout: a click on a guessed button label silently skips the game | The welcome modal's start button is "Enter cockpit", not "Start flight"; a `count()` guard hid the miss and screenshots showed the modal. Assert the HUD is visible before screenshotting. |
| 2026-10-18 | **"Now" makes pixel tests depend on the clock.** | Since 0014 the default sun is the real one, so the 35C runway-visibility test (blue-grey pixel count) passed at 05:51 CDT and failed at 08:28 CDT when the warm morning tint made asphalt r > b, on main and on every PR. Pixel/colour tests pin a preset (Noon) unless they are about the sun. |
| 2026-10-18 | **A group is seated on one patch of ground.** | 0010 first kept downtown in one THREE.Group anchored on Bank of America Plaza; `seatLandmarks()` lifts only the group, so towers 1 km away were buried 14 m or floated 4 m (the DEM changes across downtown). Put each landmark at the top level with absolute X/Z, and assert seat height against `ground.heightAt` per object. |
| 2026-10-19 | Scout: measure the start button in the modal, not the page | Playwright reported ENTER COCKPIT at y=1005 on an 844 px phone because the modal scrolls internally; 0029 already pins it, so no new ticket. Check existing tickets' acceptance criteria before filing a "gap". |
| 2026-10-19 | **An integral-only autothrottle drives the phugoid.** | `throttle += err·k·dt` reacted half a cycle late: the 4 NM autoland swung pitch −2.5…+6.3° and speed 130–159 kt with a ~28 s period while every 20 m tracking test passed. A speed-trend (proportional) term fixed it (0016). Probe pitch/IAS over a full minute, not 12 s, when touching a control law. |
| 2026-10-18 | **Measure the model against the book, not against itself.** | Every test passed while the C172 glided 4.6:1 (POH ~9:1): lift and drag were applied in body axes. `tests/flight/` now flies the model headless against cited data; gaps are `it.fails` cards with a ticket. Locally, run browser e2e with `--workers=1`: parallel SwiftShader runs time out on a laptop (6 false failures, all green serially). |
| 2026-10-19 | **A test pilot that porpoises measures nothing.** | The first C172 climb card "passed" at 697 fpm because an integral-only speed hold swung 68–84 kt and the average landed near the POH number; with the airplane actually settled it climbed 1,440 fpm. Damp the harness pilot with the speed trend and check it settles (print IAS over a minute) before trusting a card. |
| 2026-10-19 | **Contact held by a position clamp carries no load.** | The gear spring was never compressed (the clamp reset height and sink each sub-step), so the normal force was ~0 and brakes (μ 0.45) and rolling friction did nothing: a 737 rolled 2 km from 58 kt with brakes on. Normal force is now at least what the wing doesn't lift. Test braking distance, not just touchdown. |
| 2026-10-19 | **Get the real table before writing a reference.** | A hot-day card first said "+11%" from memory; POH Fig. 5-5 says +20% (960 → 1150 ft, 15 → 40 °C), which also exposed an altitude-only power lapse used for temperature. Every card cites a figure number. |
| 2026-10-19 | **Correct drag exposes tuned control laws.** | With realistic drag the 737 final needed only 13% thrust (L/D 10, real ~7.5), so the autothrottle had no room to slow down, and its integral (time constant ~4 s against the jet's ~27 s speed response) wound up into a ±1.9° phugoid. Fix the airframe data first (flap drag), then feed-forward the model's trim throttle and keep the integral near the plant's time constant. |
| 2026-10-19 | **Tune a coefficient, then check every switch that feeds it.** | #42 fitted the C172 to the POH with gear drag counted separately, but the gear key/button and tour spawns could still "retract" its fixed gear: 155 kt top speed instead of 126. Fixed-gear airframes now ignore the toggle (`spec.fixedGear`). |
| 2026-10-19 | **A stall filter must not throw away the slowest device.** | 0026 first ignored every frame over 250 ms as a "spike"; a phone drawing 3 fps (or CI's SwiftShader at 2x) would never fill a window and never step down, the exact device the ticket was for. Lone long frames are ignored; a run of them counts (clamped). Unit-test the extreme input, not just the typical one. |
| 2026-10-19 | Scout: grep before filing | No help/controls sheet, go-around mission or pattern mission existed in `src/` (checked with grep); windsock (0027) was still unbuilt, so it was promoted rather than re-filed. |
